# Generated board objects

Generated with the built-in image generation tool on 2026-09-09. The vehicle and yard-ground assets were used as style references. Runtime WebP files preserve transparent backgrounds and were resized for runtime use. Lossless PNG sources are archived under `design-audit/source-art-2026-09-09/` outside the production bundle.

Shared direction: `Use case: stylized-concept. Asset type: top-down browser puzzle game object. Match the warm painterly realism, golden evening light, material detail, color palette, and top-down perspective of the supplied vehicle and dirt-yard references. One centered object viewed from above, clear silhouette, genuinely transparent background, no text, no logo, no watermark, no surrounding scene.`

- `crate-painted-v1.webp`: square wooden shipping crate, sturdy frame, diagonal X braces, small iron corner plates and bolts.
- `hay-bale-painted-v1.webp`: round tightly rolled golden hay bale seen directly from above, individual straw texture, clean circular silhouette.
- `barrel-painted-v1.webp`: round wooden barrel seen directly from above, warm staves and dark iron hoops, clear circular silhouette.
