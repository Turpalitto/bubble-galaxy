# МЕГА-ПРОМТ: Bubble Galaxy — вирусный bubble shooter, готовый к публикации

> Источник: https://github.com/Turpalitto/bubble-galaxy (React + Vite + Canvas 2D, Yandex Games SDK).
> Цель: переписать и довести до состояния «жми Publish» — быстрая, красивая, залипательная, с онлайн-лидербордами, дейли-челленджем и виральными механиками шаринга.

## 1. Роль
Ты — senior game-developer + growth-продюсер казуальных игр. Делаешь продукт, а не демо. Никаких заглушек, TODO и «потом доделаем». Всё, что есть в UI, работает.

## 2. Стек и архитектура
- Next.js (App Router) + TypeScript + Tailwind, PostgreSQL через Drizzle ORM (`@/db`).
- Игровой движок — чистый TypeScript без React-зависимостей (`src/game/engine.ts`): детерминированная логика, фиксированный шаг обновления, события наружу через колбэки.
- Рендер — отдельный модуль Canvas 2D (`src/game/render.ts`) с поддержкой devicePixelRatio, логическое поле 460×760, вписывается в любой экран (mobile-first портрет, на десктопе — центрированная «колонна»).
- Звук — только Web Audio синтез (без бинарных ассетов): pop с ростом высоты тона по комбо, выстрел, отскок, проигрыш, победная фанфара, фоновый эмбиент-арпеджио. Всё выключаемо.
- Прогресс — localStorage (+ никнейм и токен игрока для сервера). Сервер — источник правды только для лидербордов и глобальной статистики.

## 3. Геймплей (ядро)
- Гекс-сетка 11 колонок со смещением рядов, радиус пузыря 20, ряды через R·√3.
- Прицеливание: pointer move → пунктирная траектория с предсказанием одного отскока от стены; выстрел по pointer up / клику; минимальный угол от горизонта ~8°.
- Снаряд: движение с подшагами (никаких «пролётов» сквозь пузыри), отскок от стен, прилипание к ближайшей свободной ячейке рядом с точкой контакта или к потолку.
- Совпадение ≥3 одного цвета → лопаются; «висящие» кластеры, не связанные с потолком, падают с бонусом ×2 за каждый.
- Спец-пузыри: 💣 Бомба (радиус 2 ячейки), ⚡ Молния (весь ряд), 🌈 Радуга (джокер любого цвета), 🪨 Камень (не лопается матчами — только бомбой/молнией/падением).
- Комбо: каждое подряд успешное лопание +1 к комбо и множителю (×1, ×1.5, ×2 …); промах сбрасывает. Комбо ≥5 включает FEVER: ×2 очки, свечение экрана, ускоренная музыка-пульс на 8 секунд.
- Бустеры (запас хранится в прогрессе): «Бомба-выстрел», «Радуга-выстрел», «Лазерный прицел» (полная траектория с 3 отскоками на 3 выстрела). Выдаются за 3★ уровня и за FEVER.
- Смена текущего/следующего пузыря по тапу на шутер или клавише Space.

## 4. Режимы
1. **Кампания** — 40 уровней, детерминированная генерация по seed уровня (одинаково у всех → честные рекорды). Паттерны: полные ряды, шахматка, пирамида, ромб, колонны, «соты с дырками», стены камней. Сложность растёт по числу цветов (3→7), рядов (4→9), доли камней и лимиту выстрелов. Звёзды: 3★ если осталось ≥40% выстрелов, 2★ ≥15%, 1★ за победу.
2. **Бесконечный** — каждые N выстрелов сверху добавляется ряд (N снижается с волнами: 8 → 4), число цветов растёт, проигрыш по линии опасности. Волны = уровень для лидерборда.
3. **Дейли-челлендж** — seed = дата (UTC), одинаковое поле у всех, одна официальная попытка в день, счёт публикуется в дневной таблице. Стрик дней подряд. Шаринг результата в стиле Wordle (эмодзи-карточка).

## 5. Виральные и retention-механики
- Дневной стрик с огоньком 🔥 на главном экране и напоминанием «до нового челленджа осталось HH:MM».
- Шаринг: Web Share API → fallback на копирование. Текст с эмодзи, счётом, комбо, стриком и ссылкой.
- Глобальные лидерборды (топ-50 + место игрока) по каждому режиму, дневная таблица по дате, лучший счёт по уровню кампании.
- Глобальный счётчик «🫧 лопнуто пузырей во всём мире» на главном экране (обновляется каждые 30 сек).
- Достижения (первое комбо ×5, 1000 пузырей, 3★ на 10 уровнях, волна 10 в бесконечном, дейли-стрик 7).
- Тост «Новый рекорд!», конфетти при победе, screen shake при бомбе, haptic-вибрация (navigator.vibrate) на мобильных.
- Локализация RU/EN с автоопределением языка браузера и переключателем.

## 6. Сервер (Next.js Route Handlers + Drizzle)
- `players`: id, nickname, token (секрет, возвращается один раз клиенту), created_at, total_popped, games_played.
- `scores`: id, player_id, mode ('campaign' | 'endless' | 'daily'), score, level (номер уровня / волна), daily_date (YYYY-MM-DD, nullable), max_combo, created_at.
- `POST /api/players` — создать игрока (генерирует ник «Космонавт-1234», если пустой), `PATCH` — сменить ник (по токену).
- `POST /api/scores` — принять результат (валидация: токен, лимиты счёта по режиму, троттлинг 1 запись / 3 сек), инкремент глобальной статистики.
- `GET /api/leaderboard?mode=&date=&level=&playerId=` — топ-50 лучших результатов (по одному лучшему на игрока) + ранг игрока.
- `GET /api/stats` — суммарные пузыри, игроки, партии, лидер дня.
- `GET /api/health` — healthcheck.
- Никаких секретов на клиенте. Санитизация ника (2–16 символов, стоп-слова, trim).

## 7. UX/полировка, обязательный чек-лист
- 60 FPS на мобильных: без аллокаций в горячем цикле, партиклы в пуле, DPR ≤ 2.
- Нет скролла/зумa страницы при игре (touch-action: none, overscroll-behavior: none, viewport-fit=cover, safe-area).
- Пауза при потере фокуса вкладки.
- Онбординг: первый уровень — обучающая раскладка с подсказкой «Целься в зелёные».
- Экраны: Меню, Выбор уровня (сетка со звёздами и замками), HUD (счёт, выстрелы/волна, комбо, бустеры, пауза), Пауза, Итог (звёзды, счёт, рекорд, кнопки «Дальше / Ещё раз / Поделиться / Таблица»), Лидерборд с табами, Настройки (звук, музыка, вибрация, язык, ник).
- SEO/PWA: metadata + Open Graph, manifest.webmanifest, иконки 192/512, theme-color, apple-mobile-web-app-capable.
- Готовность к порталам (Yandex Games / Poki / CrazyGames): изолированный `PlatformAdapter` с методами `ready()`, `showInterstitial()`, `showRewarded()`, `submitScore()` — веб-реализация по умолчанию, точка расширения для SDK.
