## Фаза 1: Немедленная безопасность и платформенная валидация (Now)

### 1.1. Санитизация числовых полей сохранения (P1 / Завершено)
- **Задача:** Добавить верхний порог для числовых полей `daily.streak` (константа `MAX_DAILY_STREAK = 3650`) и `daily.trophies` (константа `MAX_WEEKLY_TROPHIES = 520`) в функции `sanitizeSave()`.
- **Назначение:** Защита от числового переполнения и повреждения структуры локальных сохранений (не античит).
- **Критерии готовности:**
  - [x] Константы объявлены и используются в `sanitizeSave()`.
  - [x] Написаны unit-тесты на проверку граничных значений (ровно на границе и +1 над ней).
  - [x] Тесты `tests/save.test.ts` полностью проходят.

### 1.2. Проверка в песочнице Яндекс Игр (P1 / Высокий приоритет)
- **Задача:** Ручное натурное тестирование в черновике консоли разработчика Яндекс Игр перед публичным релизом:
  - Проверка показа реальной рекламы (interstitial по каденсу, rewarded для подсказок/пропуска).
  - Проверка синхронизации облачного сохранения между двумя разными устройствами через `player.setData/getData`.
  - Проверка записи в таблицы лидеров `yardstars` и `dailystreak`.
  - Проверка поведения при обрыве сети и переключении вкладок.
- **Критерии готовности:**
  - Отсутствие необработанных ошибок в консоли браузера при работе с боевым SDK.
  - Сохранения корректно объединяются без потери прогресса.

## Фаза 2: Архитектурная декомпозиция Presentation Layer (Next / P1)

### 2.1. Декомпозиция `src/ui/app.ts` на экранные субконтроллеры (P1)
- **Задача:** Разгрузить God Object `App` (3238 строк), выделив самостоятельные модули экранов по образцу `campaign-ending.ts`:
  - `src/ui/screens/menu-screen.ts` — главное меню и интеграция со двором.
  - `src/ui/screens/garage-screen.ts` — выбор скинов машины.
  - `src/ui/screens/levels-screen.ts` — список глав и уровней.
  - `src/ui/screens/leaderboard-screen.ts` — таблица рекордов соседей.
  - `src/ui/screens/achievements-screen.ts` — экран наград.
  - `src/ui/screens/elite-screen.ts` — Высшая лига.
- **Критерии готовности:**
  - Размер `app.ts` сокращается до роли координатора роутинга и платформы.
  - Все E2E-тесты Playwright проходят без изменений селекторов.
  - Бандл сборки остаётся в пределах текущего размера.

### 2.2. Модуляризация словарей локализации (P2)
- **Задача:** Вынести словари из монолитного `src/game/i18n.ts` (1881 строка) в отдельные файлы `src/game/locales/{ru,en,tr}.ts`.
- **Критерии готовности:**
  - Тест паритета `tests/i18n-parity.test.ts` остаётся полностью зелёным.
  - Существующие вызовы `t('...')` не требуют изменения контракта.

  - Кампания расширяется без сдвига существующих сохранённых звёзд.
